# ZhasylQala

Локальный MVP для предварительного планирования озеленения Павлодара по ТЗ `TZ_AI_ozelenenie_akimat.pages`. Он показывает полный путь от проблемной зоны на карте до подбора растений, бюджета, ухода и отчёта. Интерфейс на русском языке.

Публичный репозиторий: [temirrllan/zhasylqala](https://github.com/temirrllan/zhasylqala).

## Запуск

```bash
python3 -m http.server 4186 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:4186/](http://127.0.0.1:4186/). Из папки проекта альтернативно: `docker compose up --build`. Краткая инструкция — в [QUICKSTART.md](QUICKSTART.md). Для картографической подложки, спутниковых слоёв и климата нужен интернет. Если эти сервисы недоступны, локальные сценарии и расчёты сохраняются, но карта и контекстные данные могут не загрузиться.

## Демонстрация

1. В списке выберите «Демо-зона 1 · дефицит зелени». На карте виден **синтетический** полигон; справа — площадь, вводимые условия, статус качества и проблемы зоны. Полигоны служат примером интерфейса и не подтверждают наличие свободного грунта.
2. Измените почву, свет, близость дороги или ширину. Карточки растений показывают пригодность 0–100 и исключения по жёстким ограничениям. Выберите вид или смешанную схему 70/30. Для полигона карта покажет предварительные посадочные точки; приложение проверит, помещается ли выбранное количество при условном расстоянии между деревьями. Скачайте точки в GeoJSON для проверки на месте.
3. Измените полив и цены. Смета разбита на материалы, подготовку, доставку, посадку, уход и резерв замены; прогноз показывает 1/2/3 года, риски и эффект изменения полива.
4. Посмотрите календарь ухода и примерный эффект на 5/10/20 лет. Слева отфильтруйте проблемы, измените веса приоритета и нажмите «Составить план» для бюджета города.
5. Если текущая карта или осмотр показывают другое покрытие, заполните «Что видно сейчас» и выберите источник. Расхождение с WorldCover 2021 будет сохранено в GeoJSON и отчёте. Отметка по карте временно исключает зону из бюджетного плана до осмотра на месте.
6. Для точной точки вставьте широту и долготу в поле под инструментами карты, например `52.28201° N, 76.97125° E`. Приложение проверяет диапазон, предупреждает о переставленных координатах и отмечает точки вне района Павлодара.
7. «Скачать план» выгружает GeoJSON, «Скачать отчёт по участкам» — HTML для печати в PDF. Новые зоны можно нарисовать инструментом «Участок» и заполнить вручную. Двойной щелчок заканчивает контур; `Esc` отменяет.

Встроены 3 синтетические зоны и 3 прежние демо-точки; пользовательские участки в `localStorage` сохраняются при обновлении приложения. Точки показываются для черновика, но в бюджетную очередь входят только зоны с полигоном. Импорт GeoJSON принимает `Point` и простые `Polygon` в WGS84, проверяет координаты, замыкание контура, самопересечение и известные ошибки CRS. Отверстия, мультиполигоны и произвольные проекции требуют предварительной подготовки данных. Расчётная схема использует сетку с шагом, равным условной ширине кроны более крупного выбранного вида, и отступом в половину шага от границы. Она не учитывает сети, грунт, существующие насаждения и согласования; координаты нельзя использовать для посадки без выезда.

## Источники и пределы модели

| Данные | Источник | Использование |
| --- | --- | --- |
| Карта | [OpenFreeMap](https://openfreemap.org/) / OpenStreetMap | Подложка и привязка контуров |
| Покров, NDVI | [ESA WorldCover](https://esa-worldcover.org/en/data-access), обзорные слои 2021 года | Автоматическая классификация ячеек около 10 м; не фотография, текущая инвентаризация деревьев или карта посадочных ям |
| Климат | [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api), 2023–2025 | Сеточные средние; не измерения конкретного участка |
| Названия пород | [Сообщение акимата Павлодара](https://www.gov.kz/org/pavlodar/press/news/details/1223959?lang=ru) | Отправная точка каталога; свойства видов условные |

Значения демо-зон, характеристики растений, цены, коэффициенты роста кроны, CO₂ и задержания осадков **синтетические**. Приживаемость считает логистическая регрессия, обученная на 336 синтетических примерах экспертных правил и проверенная на 84 таких же примерах. Средняя абсолютная ошибка на этой синтетической проверке около 3,5 процентного пункта; это **не оценка точности в Павлодаре**. Прогноз 1/2/3 лет, стоимость и экологический эффект нужны для сравнения сценариев и должны быть калиброваны по фактическим посадкам и сметам.

Для демонстрации нет карты почв, инвентаризации насаждений, данных о населении и утверждённого каталога организатора. В интерфейсе эти пробелы отмечены. Местами ручная/синтетическая доля зелени зоны расходится с пятью локальными выборками WorldCover; приложение предупреждает об этом, а не подменяет одно другим. Новая отметка текущей поверхности вводится человеком: приложение не проверяет сам снимок и не удостоверяет проведение осмотра. Перед реальной посадкой нужны выезд, проверка грунта, воды, подземных сетей, права, агронома и цен.

## Файлы

- `index.html`, `style.css`, `enhancements.css`, `mvp.css` — интерфейс.
- `app.js` — карта, базовые участки, сохранение, климат, импорт/экспорт.
- `mvp.js` — зоны, подбор, сценарии, смета, риски, очередь и отчёт.
- `coordinate-input.js` — разбор и проверка координат для точного добавления точки.
- `mvp-model.js` — воспроизводимая синтетическая модель.
- `planting-layout.js` — расчёт вместимости контура и предварительных посадочных точек.
- `EXAMPLE_PLANTING_POINTS.geojson` — пример выгрузки 10 расчётных точек для синтетической зоны.
- `QUICKSTART.md` — краткая инструкция для демонстрации.
- `ARCHITECTURE.md` — структура и контракты данных.
- `AUDIT_TZ.md` — сверка с требованиями и открытые ограничения.
- `EXAMPLE_REPORT.html` — сохранённый пример демо-отчёта; актуальный отчёт скачивается из приложения.

Проверка модели: `node --test tests/*.test.js`. Код работает без сборки, хранит данные только в локальном браузере и не содержит пользовательских аккаунтов или секретов.
